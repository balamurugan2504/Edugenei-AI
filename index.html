PROJECT DOCUMENTATION

EduGenie: Google Gemini Powered Learning Assistant

EduGenie is a full-stack BCA final-year project that demonstrates how generative AI can support students through an easy-to-use learning interface.

Frontend

HTML5, CSS3 and JavaScript with a responsive dashboard and chat interface.

Backend

Node.js and Express provide API routes and keep the Gemini API key on the server.

AI Layer

Google's official @google/genai JavaScript SDK is used for Gemini text generation.

Demo mode

The project can run without an API key so the interface can be demonstrated locally.

For submission: Add your API key only to the local .env file. Never upload it to GitHub or include it in screenshots.
